# Flight Sim

Status: `PROTOTYPE ONLY`

This client is a browser preview reference for mission-bay presentation and lightweight 3D visualization.

It is not a production simulation architecture.

Do not expand it toward production quality.

Production direction:

- Unreal Engine 5
- C++ and Blueprints where appropriate
- Unreal dedicated server

Three.js is allowed here only as a preview/prototype technology.

Current behavior preserved in this prototype:

- animated mission-bay preview scene
- responsive canvas resize behavior
- telemetry and environment overlay cards
